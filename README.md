# InstaText

A website that turns an Instagram Reel into written text: paste the link, get back what was said.

Some Reels are basically someone talking through a recipe, a workout or a piece of advice, and it is easier to read them than to rewatch them several times. InstaText takes the Reel's link, fetches the video, and uses an AI speech-to-text service to write out the spoken words.

## What you can do with it

- Paste an Instagram Reel link and get a written transcript of what is said.
- See the word and character count of the transcript.
- Copy the transcript with one click.
- Download it as a text file.

Very long videos may be rejected because of a size limit on the transcription service, so shorter Reels work best.
